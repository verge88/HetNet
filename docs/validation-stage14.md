# HetNet Studio — графический интерфейс, этап 14

## Обзор

HetNet уже имел базовую браузерную страницу для отображения
событий и топологии. Этап 14 расширяет её до адаптивной
русскоязычной рабочей панели с разделами:

1. Обзор сети: настройки симулятора, топология 2G–5G и журнал.
2. Исследования: сравнительные диаграммы детекторов и эпизодов.
3. Доверие и защита: локальные HMAC/anti-replay механизмы и CLI.

Всё работает на Python 3.10+ без дополнительных runtime-библиотек
и без внешних CDN, Google Fonts или сетевой загрузки скриптов.
Node.js требуется только GitHub Actions для проверки синтаксиса
встроенного JavaScript, пользователю он не нужен.

## Как запустить

    python -m pip install -e .
    python -m hetnet serve --host 127.0.0.1 --port 8080

Откройте в браузере адрес:

    http://127.0.0.1:8080

Открывшаяся страница автоматически запускает небольшой
воспроизводимый сценарий (seed 42, 18 виртуальных секунд,
8 синтетических абонентов). Можно изменить значения и
нажать «Запустить моделирование».

Веб-интерфейс поддерживает три пресета: штатная сеть,
подделка КИЕ, потеря кворума. Разрешены длительность
5–90 секунд, 4–40 абонентов, seed 0–999999999,
масштаб трафика 0–10, тип искажения КИЕ, профиль
трёх наблюдателей, потери голосов и событий,
общий сбой зоны, допуск голосов кворума и выбор
контролируемых узлов msc2/sgsn3/mme4/dra/pcscf/amf5.

Обзор показывает:
- число сообщений, доставку, КИЕ, тревоги;
- адаптивную SVG-топологию с поколениями
  2G/3G/4G/IMS/5G, логическими рёбрами
  и ободком вокруг узлов с определёнными сбоями;
- гистограмму потока событий в десяти интервалах;
- карточки тревог;
- таблицу подписанных CU и кворума наблюдателей;
- описательные нормированные зональные признаки;
- последние 300 синтетических событий с поиском
  и фильтром по протоколу.

Кнопка «Скачать JSON» экспортирует созданный
исключительно симулятором синтетический результат
в браузере, без обращения к внешнему сервису.

## Графические исследовательские сравнения

Вкладка «Исследования» использует ТОЛЬКО
предопределённые открытые синтетические данные:

| Режим | Входные данные | Выход |
|---|---|---|
| Зональные детекторы | Короткая серия 8 симуляций с отделёнными train/test seed | Сравнение CU baseline, абсолютного остатка и peer-медианы |
| Размеченные агрегаты | 2 чистых train + 2 holdout-источника | Полнота, ложные тревоги, покрытие |
| Эпизоды | 2 train + 3 эпизодных holdout-источника | Episode recall, ложные тревоги, задержка |
| Сдвиги часов | 4 фиксированных варианта тех же 3 эпизодных источников | Изменение обнаружения при сдвиге на 0/±1/±2 бина |

Для каждого эксперимента показываются
интерактивные столбики значений основного
показателя, суммарные обнаружения и тревоги,
описание тестовой постановки и границ доверия.
Экспорт содержит ТОЛЬКО агрегированные итоги,
а не строки измерений, отдельные attack labels,
секреты HMAC или индивидуальные узловые события.

Режим зонального сравнения в UI — короткий preview
(8 прогонов). Для полного Stage 9 эксперимента
используйте исходный CLI zonal-compare.

Все метрики вычислены на синтетических
фикстурах: они не являются подтверждённой
точностью на сети оператора и не доказывают
соответствие стандартам 3GPP.

## Ограничения и безопасность локального веб-сервера

Веб-интерфейс предназначен только для
доверенного локального компьютера.

- Разрешён bind только 127.0.0.1, ::1 либо localhost.
  Слушать 0.0.0.0 или внешний IP по умолчанию запрещено.
- HTTP API ограничен GET /api/run и GET /api/study.
  Никаких API загрузки произвольного JSON, operator trace,
  trust-config, SQLite, отзыва или ротации ключей нет.
- Заголовок X-HetNet-UI: 1 обязателен при обращении к API.
  Проверяются loopback Host и Sec-Fetch-Site/Origin,
  CORS-разрешения не отправляются. Это защита
  от некоторых запросов с чужих веб-страниц,
  НО не аутентификация локального пользователя.
- Параметры URL строго перечислены, ограничены
  максимальные размеры, диапазоны и целочисленность.
  NaN, Infinity, повторяющиеся имена параметров
  и неизвестные контролируемые узлы отклоняются.
- HTTP-ответы используют no-store, nosniff,
  X-Frame-Options DENY и Content Security Policy.
- JavaScript использует textContent и создание DOM,
  не применяет разбор пользовательского HTML.
- Браузер не принимает HMAC-ключи и не читает
  приватную базу долговременного anti-replay.
  Для таких действий используйте только CLI.
- Приложение не рассчитано на размещение на публичном
  веб-сервере или в недоверенной многоарендной среде.

## Код и проверка

- src/hetnet/web_ui.py — HTML/CSS/JS интерфейс.
- src/hetnet/web.py — HTTP-сервер, ограничения API и headers.
- src/hetnet/dashboard_research.py — агрегированные
  результаты только из встроенных синтетических
  экспериментов.
- tests/test_research_stage14.py — тесты структуры
  интерфейса, изоляции данных, всех исследований,
  HTTP и запрета внешних путей/CSRF.
- GitHub Actions — Python 3.10 и 3.12, отдельный
  HTTP-test suite и node --check синтаксиса JS.

    python -m unittest discover -s tests -v
    python -m unittest discover -s tests -p test_research_stage14.py -v

## Научный статус

HetNet — дискретно-событийная абстрактная
модель процедур MAP/SS7, Diameter, GTPv2-C,
SIP и 5G SBI. Нет реального GSM/UMTS/LTE/NR
wire stack, передачи сигнальных пакетов,
правомочного операторского мониторинга или
сертифицированного 3GPP Release 18 conformance.
