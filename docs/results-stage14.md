# HetNet Studio — результаты проверки графического интерфейса, этап 14

Дата: 19 ноября 2026 года.

Референсный успешный GitHub Actions прогон:
https://github.com/verge88/HetNet/actions/runs/44503606820

На Python 3.10 и 3.12 прошли **238 unit/integration tests**
вместе с предыдущими модулями HetNet.
Отдельный HTTP/browser smoke suite включал **15 проверок**,
выполненных дополнительно на Python 3.12.
GitHub Actions также выполнил независимую проверку
синтаксиса встроенного JavaScript командой node --check
и компиляцию Python-модулей.

Никакие внешние операторские трассы или реальные
приватные HMAC-ключи для тестов не использовались.

## Проверено

- Локальный сервер отдаёт полноценную HTML-страницу,
  адаптивный CSS и JavaScript без внешних сетевых
  ресурсов и дополнительных Python-зависимостей.
- Параметры работы сценария передаются строго
  валидируемому API: длительность, subscribers,
  seed, traffic, observer-case, узловые повреждения,
  общий отказ и допуски кворума.
- API возвращает топологию, события, тревоги,
  CU-верификацию и зональные признаки.
- Исследовательский API действительно выполняет
  четыре встроенных режима: zonal, labeled,
  episodes, clock, и отдаёт только сводные
  числовые показатели, а не входные измерения.
- Браузерная страница содержит три логических
  раздела, доступные пресеты, фильтры событий,
  SVG-топологию, графики и экспорт JSON.
- Доступ к API без X-HetNet-UI отклоняется,
  а запросы с неразрешённым Origin/Host
  либо Sec-Fetch-Site запрещаются.
- Слушать 0.0.0.0 или внешний IP запрещено;
  локальные обращения по loopback разрешены.
- Неизвестные HTTP-маршруты, загрузки файлов,
  искусственно большие URL, NaN/Infinity,
  повторяющиеся параметры, недействительные
  имена узлов или неизвестные исследования
  не допускаются.
- Страница использует строгие HTTP
  no-store, nosniff, X-Frame-Options и CSP;
  динамические данные отображаются как текст,
  а не интерпретируются как HTML.
- Нет API чтения/записи trust-config,
  приватных HMAC, SQLite или сырых
  операторских материалов.

## Научные ограничения

GUI — интерфейс к абстрактному **синтетическому**
симулятору. Он не подключён к реальной сети,
не воспроизводит физическое радиопланирование
или точный протокольный стек 2G–5G,
не предоставляет настоящую независимую
внешнюю экспертизу и не является 3GPP
Release 18 conformance тестом.

Исследовательский режим zonal в GUI запускает
укороченную 8-симуляционную демонстрацию, а не
полный Stage 9 эксперимент. Численные
результаты других режимов основаны на
неизменных лабораторных файлах stages 10–12.

Проверены структурные и интеграционные
тесты браузерного API и синтаксис JavaScript,
но **автоматизированная визуальная проверка
скриншотов в разных браузерах не проводилась**.
Для окончательного утверждения визуальной
доступности и кроссбраузерности нужен
дополнительный e2e тест в настоящем браузере.
