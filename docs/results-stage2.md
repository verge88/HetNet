**Причина низкой полноты**: текущий SIP rate-detector агрегирует многочисленные атакующие INVITE в одну тревогу по корреляции. При формальном учёте каждого INVITE отдельно большая часть этой кампании считается пропущенными сообщениями. Это ограничение гранулярности измерения, а не статистически обоснованная оценка промышленного обнаружения.

**Нулевая межпрогонная дисперсия метрик** вызвана стабильной структурой включённых атаки и правил без фоновых ошибок; это **не** свидетельство устойчивости при изменении оператора/сети. Исходные таблицы результатов диссертации из §§ 3.8, 4.1–4.8 этими числами не воспроизводятся. Нет сравнения с ML моделями, bootstrapping/Wilcoxon и отдельных ground truth для КИЕ-компрометации.

**Следующее условие для исследовательской валидности:** раздельно оценивать эпизоды массовых атак и сообщения, варьировать сценарии/перегрузку/маскировку, использовать temporal train/test split, независимые референс-трассы, калибровать фоновые профили; затем строить сравнимые PR-AUC/F1, confidence intervals и статистические тесты. Пока конформность 3GPP ограничена логическими инвариантами модели.
